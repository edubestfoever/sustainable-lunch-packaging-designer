# Sustainable Lunch Packaging Designer

An offline single-file educational web app for Year 3-4 students designing sustainable lunch snack packaging.

## Files

- `index.html` - the complete app. Upload this to GitHub Pages as the homepage.
- `.nojekyll` - keeps GitHub Pages from applying Jekyll processing.

## Publish With GitHub Pages

1. Create a new public GitHub repository.
2. Upload the files in this folder to the root of the repository.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Click `Save`.

Your public link will look like:

```text
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/
```

## Classroom Use

The app uses pure HTML, CSS and JavaScript. It has no backend and no external assets, so it can also run by opening `index.html` directly in a browser.
